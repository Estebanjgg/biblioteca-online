# Biblioteca Online

Este es un sistema de gestión de una biblioteca virtual donde puedes administrar libros, autores, categorías, usuarios y préstamos.

## Características

- CRUD de Libros, Autores y Categorías
- Gestión de Usuarios
- Préstamos y Compras
- Dashboard con estadísticas
